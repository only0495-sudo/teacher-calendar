# 課日 v2｜老師的教學行事曆

本機預覽：http://127.0.0.1:8765/ 。也能開啟 dist/index.html，但附件儲存及未來 App 功能建議透過網站使用。dist 必須整個資料夾一起搬移，已不再是單檔 HTML。

## 此版操作

- 老師／學期工作區：建立新工作區、切換，各自保存課表、進度、段考與原始附件。這是本機資料分組，不是登入帳號，不具不同使用者的存取隔離。
- 上傳行事曆與課表：PDF／PNG／JPEG／WebP（20 MB 內）存入 IndexedDB，可預覽、下載，並逐列整理成課表或活動；檢查整理結果後才套用。目前沒有 OCR 或 AI 自動辨識。PDF 是否內嵌顯示取決於瀏覽器；也可下載原檔查看。
- UTF-8 CSV：提供範本、預覽、日期與欄位驗證。相同班級＋科目會更新固定課表；其他課程與進度保留。活動合併且相同項目不重複匯入。Excel 可另存 CSV；不直接解析 xlsx。
- 日期早於臺北今天時顯示灰色，但仍可補記進度。月曆只顯示班級（每堂一列），時間保留在當日詳情。
- 自然探究與實作：新增探究班級，設定預定總堂數，記錄上課日期、時間、分鐘、換課老師與備註。每筆一堂，連堂分列；只有確認完成才扣除，日期經過不代表實際已上課。也提供可選的「未來已排定堂數」計算法。
- 所有一般課程支援全天停課及單堂補課；尚不支援部分節次停課。調整課表後舊進度保留於紀錄頁。

## 堂數規則

第一次：學期開始日至第一次段考開始前。
第二次：第一次段考結束翌日至第二次段考開始前。
第三次：第二次段考結束翌日至第三次段考開始前。

各區間只算尚未開始的課，計算起點取「區間起點、學期起點、今天」之最大值；同日已到開始時間的課不算。停課不重複扣除，明確新增的補課另計。一般課程不超出學期起訖。

探究預設：剩餘 = max(0, 學期預定總堂數 − 已確認完成堂數)。另列已完成分鐘、未來排課及已過期但尚未確認課程。探究實作以獨立日期紀錄為準，不受段考與一般停課事件自動取消；須自行修改或刪除未實施的排課。

## 資料與備份

主資料存 localStorage（keri-workspaces-v2），附件存 IndexedDB（keri-files）。原本 v1 資料會遷移，舊 key 保留，不覆蓋；舊版 JSON 備份仍可讀取。JSON 匯出以當前工作區為單位，還原會新增工作區，不覆蓋原資料。附件二進位內容不在 JSON 備份中，換裝置前請另外保留原始檔。

清除瀏覽器資料會失去本機資料；file://、localhost 與正式站為不同儲存來源。尚無帳號、跨裝置同步、OCR、雲端儲存或推播。

預載假日僅涵蓋示範學期，來源：https://www.dgpa.gov.tw/information?pid=12685&uid=30 。新學期不自動下載假日，需依學校正式行事曆匯入。建立新工作區會產生三次暫定段考，必須依學校資料調整。

## App 準備與架構

- dist/engine.js：不依賴畫面或瀏覽器儲存的日期、段考與探究計算；可由 Node 測試，也可供未來 App 重用。
- dist/storage.js：可替換的資料儲存介面。後續接登入及後端 API，不能把本機工作區當成權限系統。
- dist/app.js、dist/features.js：畫面及操作。
- dist/styles.css：桌面／手機響應式版面。
- dist/manifest.webmanifest、icon.svg、sw.js：PWA 基礎。僅 HTTPS 時註冊 Service Worker，本機開發不快取；快取僅包含程式殼，不包含外部請求或附件。程式更新時須調整 CACHE 版本。實際手機安裝、離線啟動與不同瀏覽器相容性仍需部署後驗證；尚未完成原生 App 封裝或商店上架。
